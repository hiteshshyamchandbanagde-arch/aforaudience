## Testing gotchas worth keeping (from earlier this session, still valid)

- Next.js dev-mode's error-indicator overlay (<nextjs-portal>) sits at the same screen region as the mobile bottom nav's first item and intercepts real Playwright pointer clicks there. Use locator.dispatchEvent('click'), not .click().
- trailingSlash: true - always include the trailing slash in Playwright URL glob patterns against this app.
- The login form's identifier field is not input.first() - MobileTopBar.tsx's global search input renders on /login too and comes first in the DOM. Target input[placeholder*="AFA code"] directly.
- Next 16 won't run a second dev server in the same directory, even on a different port; a node_modules junction into a git worktree crashes Turbopack. Use a real npm ci in the worktree instead.
